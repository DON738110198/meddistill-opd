# Public reports

Only the compact public result summary is versioned. Detailed local ledgers, checkpoint URIs,
prediction caches and historical decision reports remain ignored because they can contain
provider-specific paths or benchmark-derived text.

- [`RESULTS.md`](RESULTS.md): headline metrics, mechanism findings and claim boundaries.
- [`../results/final_metrics.json`](../results/final_metrics.json): machine-readable plotting data.
